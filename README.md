### About me

Software Engineer with commercial experience in full-stack development: backend services in **Java and Spring Boot**, web applications in **Angular** and mobile applications in **Flutter**. I work API-first, treating the OpenAPI contract as the shared reference point between backend and client teams, and I place strong emphasis on clean architecture, data consistency and maintainable code.

I hold an **MSc in Computer Science** from Kielce University of Technology. My thesis focused on procedural terrain generation controlled by large language models, combined with automated, ML-based quality evaluation.

- **Focus areas:** backend architecture, REST API design, multi-tenant systems
- **Interests:** applied AI and LLMs, computer graphics, game development
- **Languages:** Polish (native), English
